# TexBody^^

> Скриптовый язык программирования, который работает **прямо в браузере**.
> Один HTML-файл — язык + редактор + справочник + файловая система.

[![Открыть в браузере](https://img.shields.io/badge/🚀_Попробовать-открыть_в_браузере-00fff2?style=for-the-badge)](https://molniar.github.io/TexBody/)

---

## 📖 Что это такое

**TexBody^^** — это язык программирования, вдохновлённый простотым синтаксисом и мощью современных скриптовых языков. Он работает **прямо в браузере**, не требует установки, компиляции и настройки.

Просто открой ссылку — и пиши код.

```TB^^
name = "Мир"
Tex>Привет, @name!<
```

Вывод:
```
Привет, Мир!
```

## ✨ Возможности

### 🌐 HTTP-запросы
Полноценный HTTP-клиент с поддержкой JSON.

```TB^^
user = http.get.https://api.github.com/users/octocat!
Tex>Логин: @user.login<
Tex>Имя: @user.name<

response = http.post.https://httpbin.org/post!{"name": "Tex"}
Tex>Статус: @response._status<
```

Поддерживается: `GET`, `POST`, `PUT`, `DELETE`, загрузка картинок (`http.image`).

### 📁 Работа с файлами и папками
Виртуальная файловая система работает в браузере.

```TB^^
file.write("hello.txt", "Привет, мир!")
content = file.read("hello.txt")
Tex>@content<

folder.create("data")
folder.list("data")
```

### 🖼️ Картинки → ASCII-арт
Уникальная фича: загрузка картинки и конвертация в ASCII-арт.

```TB^^
img = http.image.https://example.com/cat.png!
Tex ascii.80>@img<
Tex ascii.color.80>@img<
```

### ⏰ Дата и время
```TB^^
Tex>Сейчас: @time.now!<
Tex>Сегодня: @time.date!<
Tex>Год: @time.year!<
Tex>День недели: @time.weekday!<
Tex>Формат: @time.format("DD.MM.YYYY HH:mm")!<
```

### 📦 Пакеты (динамические массивы)
Индексация **с единицы**, поддержка **отрицательных индексов**.

```TB^^
nums = Pack<10, 20, 30>
nums +> 40           // добавить в конец
nums +2> 15          // вставить на позицию 2
nums -1>             // удалить первый
nums -2>             // удалить по индексу 2

Tex>Первый: @nums.1<
Tex>Последний: @nums.-1<
Tex>Размер: @nums.size<
```

### 🔧 Функции
```TB^^
tool sum.a.b {
    result = a + b
    give @result
}

x = sum.5.3!
Tex>5 + 3 = @x<
```

### 🎲 Случайные числа

**Одно число в диапазоне:**
```TB&^^
dice = random.1.6!
Tex>Выпало: @dice<
```

**Несколько чисел сразу (возвращает Pack):**
```TB^^
dice5 = random.1.6:5!
Tex>5 бросков: @dice5<
// Пример: Pack<3, 6, 1, 4, 2>
```

**Случайный элемент из пакета:**
```TB^^
fruits = Pack<яблоко, банан, вишня, апельсин>
Tex>Сегодня едим: @random.from.@fruits!<
```

### 📚 Модули
```TB^^
// math.tb^^
tool square.n {
    give @n * @n
}

// main.tb^^
import "math.tb^^" use math
Tex>4² = @math.square.4!<
```

### 🧩 JS-модули (песочница)
Можно загружать внешние JS-библиотеки:

```TB^^
import js "https://cdn.jsdelivr.net/..." use lib
```

### 🔮 Нечёткое сравнение
```TB^^
? (@a ~==:5 @b) {
    Tex>Числа близки<
}
```

### 🎯 Условия и циклы
```TB^^
// Условие
? (age >= 18) {
    Tex>Взрослый<
}
!? (age >= 14) {
    Tex>Подросток<
}
! {
    Tex>Ребёнок<
}

// Цикл while
i = 0
?? (i < 5) {
    Tex>@i<
    i^^
}

// Цикл for
?? (j = 0, j < 5, j^^) {
    Tex>@j<
}

// Перебор пакета
?? (item : @nums) {
    Tex>Элемент: @item<
}
```

### ✂️ Строковые методы
```tex
text = "Привет мир"
Tex>@text.upper!<
Tex>@text.cut." "!<        // Pack<Привет, мир>
Tex>@text.swap."мир"."Tex"!<
```

### 📊 Встроенные функции
```TB^^
nums = Pack<5, 12, 3, 8>
Tex>Максимум: @max.@nums!<
Tex>Минимум: @min.@nums!<
Tex>Сумма: @sum.@nums!<
Tex>Модуль: @abs.-42!<
Tex>Случайное: @random.1.100!<
```

### 🎨 Вывод с форматированием
```TB^^
Tex>Строка 1\>Строка 2\>\>С отступом<

Tex>>Многострочный
вывод
без ограничений<<
```

## 📖 Полный справочник

В редакторе есть **встроенный справочник** на 9 вкладок:
- 📝 Синтаксис
- 🔤 Типы данных
- 📦 Пакеты
- 🌐 HTTP
- 📁 Файлы
- ⏰ Время
- 🔧 Функции
- 📦 Модули
- ✂️ Строки

Нажми кнопку **«📖 Справочник»** в редакторе.

## 🛠️ Что внутри

- **Интерпретатор** на чистом JavaScript
- **Редактор** на CodeMirror с кастомной подсветкой для TexBody
- **Автодополнение** анализирует переменные и функции прямо из кода
- **Виртуальная ФС** в localStorage
- **Встроенная консоль ввода** (без `prompt()`)
- **Панель переменных** обновляется в реальном времени
- **Экспорт проекта** в .zip
- **Тёмная и светлая темы**
