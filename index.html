📦 Пакеты — главная фича

nums = Pack<10, 20, 30>

nums +> 40 // Добавить

nums +3> 25 // Вставить по индексу 3

nums -2> // Удалить по индексу 2

Tex>@nums.1 // 10 (индексация с 1)

Tex>@nums.-1 // 40 (отрицательный индекс)

Tex>@nums.size // 4 (длина)

🔹 Операции с пакетами

+> значение — добавить
+N> значение — вставить по индексу N
-> — удалить первый
-N> — удалить по индексу N
-> значение — удалить по значению

🔹 Перебор пакета

?? (item : @nums) {
Tex>@item
}

✂️ Работа со строками

🔹 Разбиение

@text.cut." "! — → Pack
"a b c".cut." "! → Pack<a,b,c>

🔹 Склейка

@pack.join."-"! → строка
Pack<a,b,c>.join."-"! → "a-b-c"

🔹 Замена

@text.swap."старое"."новое"!
"Привет мир".swap."мир"."Tex"! → "Привет Tex"

🔹 Обрезка

@text.trim!
" Привет ".trim! → "Привет"
